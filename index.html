PROJ-001 / Cloud Security
Cloud Ransomware Detection System
Cloud-native ransomware detection on GCP. A lightweight Python detection function continuously watches storage buckets for ransomware-style file modification patterns. On trigger, a second function automatically isolates the affected VM by revoking its network access, while a third handles scheduled backups so encrypted data can be recovered without a payout — the whole pipeline is serverless and coordinated through Pub/Sub events for near real-time response.
GCP Cloud Functions Pub/Sub Python Compute Engine +3 more
Key feature: Automatically isolates an infected VM in under 10 seconds — no human intervention required.
→ 96.3% detection accuracy · Sub-10s automated VM isolation
PROJ-002 / Enterprise Network Security Home Lab
Enterprise Network Security & SOC Lab
Designed and deployed an 8-VM enterprise cybersecurity lab replicating a small enterprise network end-to-end: an OPNsense firewall handles routing, NAT, and inter-segment policy, while a Windows Server 2022 domain controller manages Active Directory, group policy, and centralized authentication. Kali Linux, Metasploitable 2, and OWASP BWA sit in an isolated segment for attack simulation, with Wazuh aggregating logs and alerts across all 8 VMs for centralized security monitoring — alongside core network services like DHCP, DNS, and NAT.
VMware Workstation OPNsense Active Directory Windows Server 2022 Windows 10 Kali Linux Metasploitable 2 OWASP BWA Wazuh Networking +8 more
Key feature: Centralized Wazuh SIEM correlates logs and alerts across all 8 VMs in real time.
